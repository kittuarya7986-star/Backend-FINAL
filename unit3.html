Unit III

Handling HTML Form with PHP

Web forms collect user input on the browser interface and dispatch it to backend server scripts for processing, validation, and storage.

1. Form Submission: GET vs. POST Method

Feature GET Method POST Method
Data Transmission Appends key-value pairs to the URL query string (?key=value). Encapsulated in the HTTP request body payload.
Security & Visibility Data is visible in the browser address bar and web logs. Never use for passwords. Data is not exposed in the browser address bar.
Data Volume Limits Restricted by URL length constraints (~2048 characters). Supports large payloads, file attachments (multipart data).
Browser Caching Can be bookmarked, cached, and reloaded safely (idempotent). Cannot be safely bookmarked; re-submitting requests confirmation.
PHP Superglobal $_GET $_POST

2. Complete Server-Side Form Handling & Validation Script

Robust applications must never trust client-supplied input. Server-side validation inspects empty fields, formatting regex, and escapes outputs against Cross-Site Scripting (XSS).

<?php
// Form processing script: process_form.php
$name = $email = $course = "";
$errors = [];

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // 1. Validate and sanitize Name
    if (empty($_POST["name"])) {
        $errors['name'] = "Full name is required.";
    } else {
        $name = trim($_POST["name"]);
        if (!preg_match("/^[a-zA-Z-' ]*$/", $name)) {
            $errors['name'] = "Only letters and spaces are allowed.";
        }
    }

    // 2. Validate and sanitize Email
    if (empty($_POST["email"])) {
        $errors['email'] = "Email address is required.";
    } else {
        $email = trim($_POST["email"]);
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            $errors['email'] = "Invalid email format.";
        }
    }

    // 3. Process if clean
    if (empty($errors)) {
        // Safe to proceed to database layer
        $safeName = htmlspecialchars($name, ENT_QUOTES, 'UTF-8');
        echo "Registration Successful for " . $safeName;
    }
}
?>
