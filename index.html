Syllabus Overview

Web Technologies Course Curriculum

This portal is structured to cover all four core academic modules for BCA Semester III, bridging fundamental networking protocols, dynamic server-side programming in PHP, client-server data flow, and relational database management using MySQL.

Unit I: Introduction to Internet Technologies

Explores the TCP/IP stack, HTTP/HTTPS request-response cycles, DNS resolution mechanics, HTML document structure, and the critical boundaries between client-side and server-side execution.

Explore Unit I →

Unit II: PHP Fundamentals

Delves into PHP core syntax, variable scopes, data typing, operators, conditional branching, iteration structures, and built-in string manipulation functions.

Explore Unit II →

Unit III: Forms & Server Validation

Examines HTTP form transmission using GET vs. POST, sanitization patterns via superglobals ($_POST, $_GET), and rigorous server-side validation techniques.

Explore Unit III →

Unit IV: MySQL & Connectivity

Focuses on Relational Database Design, DDL/DML operations, secure PHP-MySQL connectivity via PDO and MySQLi, and CRUD execution with Prepared Statements.

Explore Unit IV →

Technical Stack & Execution Environment

  • Server Environment: Apache 2.4+ / Nginx with PHP 8.x
  • Database Engine: MySQL 8.0+ / MariaDB 10.4+
  • Standard Protocols: HTTP/1.1, HTTP/2, DNS (UDP/TCP Port 53), TCP 3-Way Handshake
  • Best Practices: Prepared statements against SQL Injection, input sanitization, strict error reporting, separation of concerns.
