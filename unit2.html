Unit II

PHP Syntax, Variables, Control Structures & Functions

PHP (Hypertext Preprocessor) is an open-source, interpreted server-side scripting language dynamically embedded into HTML or executed as backend APIs.

1. Syntax, Variable Declaration & Data Types

PHP scripts start with <?php and end with ?>. All variables are declared with a leading dollar sign ($) and follow dynamic typing.

<?php
// Data types in PHP
$studentName = "Kanishka Sharma";  // String
$semester    = 3;                  // Integer
$gpa         = 3.88;               // Float
$isEnrolled  = true;               // Boolean
$subjects    = ["C", "PHP", "DBMS"];// Indexed Array

echo "Student: $studentName | Semester: $semester";
?>

2. Operators & Decision Making

PHP supports arithmetic, assignment, comparison (including strict identity === vs equal ==), and logical operators.

<?php
$score = 82;

if ($score >= 90) {
    $grade = "A+";
} elseif ($score >= 75) {
    $grade = "A";
} elseif ($score >= 60) {
    $grade = "B";
} else {
    $grade = "Pass";
}

// Switch-case construct
switch ($grade) {
    case "A+":
    case "A":
        echo "Distinction Performance";
        break;
    default:
        echo "Satisfactory Performance";
        break;
}
?>

3. Looping Constructs

Standard iterative structures include for, while, do-while, and the associative array traversal loop foreach.

<?php
$courseUnits = [
    "Unit 1" => "Internet Technologies",
    "Unit 2" => "PHP Core",
    "Unit 3" => "Forms & Validation",
    "Unit 4" => "MySQL Integration"
];

foreach ($courseUnits as $unitKey => $unitTitle) {
    echo "$unitKey: $unitTitle\n";
}
?>

4. Essential Built-in String Functions

Function Description Example Usage
strlen($str) Returns length of string strlen("BCA") → 3
strtoupper($str) / strtolower($str) Case transformations strtoupper("php") → "PHP"
strpos($haystack, $needle) Finds offset of first occurrence strpos("BCA Semester 3", "Semester") → 4
substr($str, $start, $len) Returns segment of string substr("Database", 0, 4) → "Data"
trim($str) Strips whitespace / control characters trim(" valid input ") → "valid input"
htmlspecialchars($str) Converts special characters to HTML entities Prevents XSS attacks in dynamic outputs
