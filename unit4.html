Unit IV

Database Connectivity with MySQL

Relational Database Management Systems (RDBMS) like MySQL persist dynamic application states. PHP interfaces with MySQL natively via mysqli or PDO (PHP Data Objects).

1. Database Schema & Table Creation (DDL)

SQL script to initialize an academic student registry database:

-- Create Database
CREATE DATABASE IF NOT EXISTS bca_academic_db;
USE bca_academic_db;

-- Create Students Table
CREATE TABLE IF NOT EXISTS students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    roll_number VARCHAR(20) NOT NULL UNIQUE,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(120) NOT NULL UNIQUE,
    semester INT NOT NULL DEFAULT 3,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

2. PHP Database Connection Script (db_connect.php)

Using modern object-oriented mysqli with strict exception handling:

<?php
$host     = "localhost";
$username = "root";
$password = "";
$dbname   = "bca_academic_db";

// Enable strict MySQLi error reporting
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);

try {
    $conn = new mysqli($host, $username, $password, $dbname);
    $conn->set_charset("utf8mb4");
} catch (mysqli_sql_exception $e) {
    // Log exception details securely and display friendly message
    error_log($e->getMessage());
    die("Database Connection Failure: Unable to establish server handshake.");
}
?>

3. Prepared Statements for Data Insertion (Preventing SQLi)

Directly concatenating user input into SQL queries enables SQL Injection. Prepared statements parameterize inputs safely.

<?php
require_once "db_connect.php";

$rollNo = "BCA2601";
$name   = "Ishaan Verma";
$email  = "ishaan.v@example.edu";
$sem    = 3;

// 1. Prepare template
$stmt = $conn->prepare("INSERT INTO students (roll_number, full_name, email, semester) VALUES (?, ?, ?, ?)");

// 2. Bind parameters ('sssi' = string, string, string, integer)
$stmt->bind_param("sssi", $rollNo, $name, $email, $sem);

// 3. Execute
if ($stmt->execute()) {
    echo "Record inserted successfully with ID: " . $stmt->insert_id;
} else {
    echo "Execution failed: " . $stmt->error;
}

$stmt->close();
?>

4. Data Retrieval & Result Rendering (SELECT Query)

Querying persistent records and rendering safely in an HTML structure:

<?php
require_once "db_connect.php";

$sql = "SELECT id, roll_number, full_name, email, semester FROM students ORDER BY id DESC";
$result = $conn->query($sql);

if ($result->num_rows > 0) {
    echo "<table border='1'>";
    echo "<tr><th>ID</th><th>Roll No</th><th>Name</th><th>Email</th><th>Semester</th></tr>";
    
    while ($row = $result->fetch_assoc()) {
        echo "<tr>";
        echo "<td>" . htmlspecialchars($row['id']) . "</td>";
        echo "<td>" . htmlspecialchars($row['roll_number']) . "</td>";
        echo "<td>" . htmlspecialchars($row['full_name']) . "</td>";
        echo "<td>" . htmlspecialchars($row['email']) . "</td>";
        echo "<td>" . htmlspecialchars($row['semester']) . "</td>";
        echo "</tr>";
    }
    echo "</table>";
} else {
    echo "No student records found.";
}

$conn->close();
?>
